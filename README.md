# Nipzz Site on GitHub Pages

This package contains your website prepared for GitHub Pages. The original `nipzzsite.html` has been copied to `index.html`, the default homepage filename used by GitHub Pages.

## Publish the website

1. Sign in to GitHub and create a new repository.
2. Upload `index.html` to the top level of the repository.
3. Open the repository's **Settings** and select **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for the Pages deployment to finish. GitHub will show the published URL in the Pages settings.

## Notes

- Keep `index.html` in the repository root, not inside another folder.
- The page may load external resources if the original HTML references them.
- This package is prepared locally. It has not been uploaded to GitHub or published.
